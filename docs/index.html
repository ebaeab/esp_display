// System Architecture

Core Modules

▒
LCD Driver
esp_lcd_panel_hx8369.c
HX8369A 面板驱动，通过 Intel 8080 并行接口（8-bit）与 ESP32-S3 通信，支持 16-bit RGB565 色彩空间。
◆
LVGL Graphics
components/lvgl/
LVGL v8.x 图形库，提供丰富的 UI 组件、动画和渲染引擎，双缓冲 PSRAM 分配确保流畅显示。
▸
Touch Input
GT9XX + gt911demo.cpp
GT911 电容触摸屏驱动，I2C 总线 400kHz 通信，20ms 轮询扫描，支持多点触摸坐标上报。
▣
Input Bridge
lv_port_indev.c
将 GT911 触摸事件桥接到 LVGL 输入设备接口，实现触摸坐标到 UI 交互的无缝转换。
◉
GUI Task
lvgl_gui.c
FreeRTOS 任务，初始化 LCD 硬件、LVGL 引擎、背光 PWM，运行主事件循环和 UI 渲染。
◕
I2C Host
myi2c.c
I2C 主机驱动初始化，400kHz 时钟频率，为 GT911 触摸控制器提供总线通信基础。
// Initialization

Boot Sequence

STEP 01
NVS Flash Init
初始化 NVS Flash 存储，处理版本不兼容时自动擦除重建。
STEP 02
GT911 Touch Task
创建触摸扫描任务（Core 1），初始化 I2C 总线，以 20ms 间隔持续轮询触摸事件。
STEP 03
LCD & LVGL Init
初始化 Intel 8080 总线、HX8369A 面板、LVGL 库，分配 PSRAM 双缓冲区。
STEP 04
UI Render Loop
启动背光 PWM，注册输入设备，运行 LVGL widgets demo，进入主事件循环。
